# premier-league-2025-2026-power-bi
A learning project analyzing the 2025–2026 Premier League season using Power BI.
About This Project
This is a personal learning project created using Microsoft Power BI to explore and analyze the 2025–2026 Premier League season.
Project Objectives
Analyze match results across the season.
Explore team performance at home and away.
Compare goals scored and goals conceded.
Calculate wins, draws, losses, and goal difference.
Practice data cleaning, data modeling, and DAX measures.
Tools Used
Microsoft Power BI Desktop
Power Query
DAX (Data Analysis Expressions)
What I Learned
Through this project, I practiced transforming football match data, creating a data model, writing DAX measures, and building interactive dashboard pages.
This project is part of my ongoing journey to learn data analysis through hands-on practice.
Project Status
Completed as a learning project. I plan to continue improving my data analysis skills through future projects.
